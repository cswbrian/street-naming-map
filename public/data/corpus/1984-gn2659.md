Notice is hereby given under section 111C(1)(a) of the Public Health and Urban Services Ordinance,
Chapter 132 that the following street in Ngong Ping, Lantau Island, New Territories will be known
as from the date of this notice as described hereunder;—
Description Name
' Road commencing at its junction with SHAM WAT ROAD NGONG PING ROAD
and running generally in a south-easterly direction for about
290 metres where it bends to run in a north-easterly direction for
about 140 metres; it then curves to run in a south-easterly
direction for about 130 metres and then turns to run in a
north-easterly direction for about 410 metres before it bends to
run northerly for about 310 metres; it continues to run in a
north-easterly direction for about 510 metres and then bends to
run generally in an easterly direction for about 260 metres where
it terminates at a roundabout near Po Lin Monastery as shown
coloured pink on Plan No. ISRM 1.
